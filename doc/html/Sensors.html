Sensor Layer and Future Instruments

The physics core returns the true non-gravitational acceleration, torque, angular rate and angular acceleration. A NonGravForces.sensor.Sensor subclass maps these to what one instrument reads and supplies partials with respect to its calibration parameters. Calibration and quality control are written against the abstract interface, so a new instrument is one new class.

  • Electrostatic (GRACE-FO, MAGIC): bias vector, full 3x3 scale matrix, CoM-offset coupling, CRN filter.
  • AtomInterferometer (CARIOQA, hybrid CAI): phase = k_eff a T^2, dead time, phase ambiguity, rotation compensation input.
  • DragFree: residual acceleration after control (LISA-Pathfinder heritage).
  • Optomechanical / MEMS: subclass with its own noise model; no core changes.
