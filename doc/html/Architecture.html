Architecture

Eight layers, each depending only on those below it (L7, quality control, moved to timeSeriesPreparation.qc and was deleted in 0.14.0). The kernel returns per-panel forces and never sums internally; the environment computes no geometry; NonGravForces.Model is the single point of access and composes the rest.

Two evaluation paths are kept side by side by design: the vectorised MATLAB path (Model.accel, Model.series) for an arc, and the pointwise compiled path (kernel.singleEpoch over mex/ngfKernel.c) for an integrator's right-hand side. Neither is a fidelity tier of the other and neither is justified by speed; they must agree, and a test measures that they do.

Constraint C2: base MATLAB and the Parallel Computing Toolbox only. auditPackage.py refuses calls into any other product, in code and in help text.
