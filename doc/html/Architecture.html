Architecture and Workflow

The one rule: NonGravForces computes forces and torques and nothing else. Time, frames, ephemerides and attitude kinematics are referenceSystem; L1B reading is gracefoReading; orbit integration is gjToolbox (odeSuite); estimation, whitening and data snooping are lsqvce. None of them is copied, vendored or wrapped.

A layer calls only lower layers plus the four dependencies. One kernel: all surface forces are per-panel arrays F_k in the body frame; net force and torque are two reductions. Sources, not effects: the radiation kernel consumes a source list {direction, pressure, band}; SRP is one source, Earth radiation is 2M sources; fidelity is data, not code paths.

Workflow (GRACE-FO calibration)

  1. io: read GNV1B (ITRS to GCRS via referenceSystem), SCA1B (conjugated once), ACT1B, THR1B, MAS1B
  2. geom: macro model, AttitudeProvider (slerp), thermal state
  3. env: density and wind, Sun and eclipse, Earth radiance, magnetic field → source list
  4. kernel via Model.series: a_ng, tau, partials, provenance
  5. sensor: Electrostatic.observe adds CoM coupling and CRN filtering; partials w.r.t. bias/scale
  6. qc.screen: residuals → outliers, impulses (THR1B priors), jumps → mask + event table
  7. app.calibrate: design matrix (bias spline, 3x3 scale, jump columns) → lsqvce.adjust with ARMA whitening and snooping
