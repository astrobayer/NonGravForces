Getting Started

This page is the short path from a fresh clone to a first evaluation. The user guide (doc/src/NonGravForces_UserGuide.tex) is the long one, and the theory document (doc/src/NonGravForces_Theory_and_Implementation.tex) describes every model and every test. Neither PDF is committed: the CI job theory builds both on every push and attaches them to the run as the artefacts userGuide and theoryDocument; locally, pdflatex in doc/src builds them.

1. What you need

MATLAB R2026a, base MATLAB only (the Parallel Computing Toolbox is used when present); the MinGW-w64 C compiler support package for the MEX targets; gfortran only for the opt-in DTM2020 backend. Five sibling toolboxes, set up in this order:

run('...\referenceSystem\setupReferenceSystem.m')                 %% time, EOP, frames, Sun/Moon
run('...\gracefoReading\setupGraceFOReading.m')                   %% the L1B readers
run('...\odeSuite\gjToolboxSetup.m')                              %% app.DynamicsSource (integrator)
run('...\timeSeriesPreparation\setupTimeSeriesPreparation.m')     %% CRN filter, QC, Arc
run('...\lsqvce\lsqvce_setup.m')                                  %% the calibration estimator

2. Set up and build

cd('...\NonGravForces'); setupNonGravForces    %% path, dependency report, pinned fetches
NonGravForces.buildMex                          %% msis, msis21, hwm14, dtm2020, rhs, kernel

Setup is the only part of the toolbox that touches the network. Third-party model sources and data (NRLMSISE-00, NRLMSIS 2.1, HWM14, DTM2020, IGRF, CERES, the DE440 kernel) are not redistributed here: setup fetches each at a pinned commit or SHA-256 the first time it runs and says so. 'FetchMsis', 'FetchData' and 'FetchKernels' take "never" to leave the network alone. With a DATAPOOL ('DataPool' or the environment variable) setup also fetches the observation data of the reference days. buildMex refuses rather than fetching: an installer may reach the network, a build step may not.

3. Verify

runNgfTests                      %% the suite; 'ExcludeSlow', false adds the speed tests
matlab -batch ciGate             %% what CI runs: the suite, the category audit, the verdict

4. A first evaluation

On the committed excerpts of GRACE-C, 2020-01-01. The standard preset multiplies NRLMSISE-00 by an observed daily density scale and refuses to evaluate without one:

f   = @(varargin) fullfile(pwd, 'data', varargin{:});
eop = referenceSystem.readEop(f('eop', 'finals2000A_2019-09_2020-03.all'));
sw  = NonGravForces.io.spaceWeather(f('spaceweather', 'SW-All_2019-09_2020-03.csv'));
cls = NonGravForces.io.spaceWeather(f('spaceweather', 'radio_flux_adjusted_observation_2007-09_2008-03_2019-09_2020-03.txt'));
swarm = string(f('samples', 'swarm', "SW_OPER_DNS" + ["A" "B" "C"] + "POD_2_2020-01-01_2020-01-03.csv"));
S   = NonGravForces.env.densityScale(swarm, sw, 'Fallback', NonGravForces.env.densityDriverScale(sw, cls));
[ep, r, v] = NonGravForces.io.readGNV1B(f('samples', 'GNV1B_2020-01-01_C_04.txt'), 'Eop', eop);
[eq, q]    = NonGravForces.io.readSCA1B(f('samples', 'SCA1B_2020-01-01_C_04.txt'));
att = NonGravForces.geom.AttitudeProvider(eq, q);
M   = NonGravForces.Model(NonGravForces.geom.graceFO("C"), NonGravForces.Options("standard"), ...
          'Attitude', att, 'Eop', eop, 'SpaceWeather', sw, 'DensityScale', S);
[a, info] = M.accel(ep, r, v, att.at(ep));     %% 3xK m/s^2 in the body frame; info.drag, .radiation, .thermal

5. The demos

Each is a working sequence of public calls, and each is EXECUTED BY THE GATE (tests/tNgfDemos.m), so an API that moves breaks the demo in CI rather than in front of a reader:

demoForceBudget         %% per-effect budget, two presets side by side
demoDensityInversion    %% recover a planted density scale
demoGraceFOCalibration  %% recover a planted bias and scale
demoCAI                 %% cold-atom accelerometer, and why it needs the attitude rate

Then doc NonGravForces for the function reference, and help NonGravForces.<unit> for any unit: every help block follows one template (syntax, arguments with units and defaults, outputs, accuracy, errors, references, an example).
