Getting Started

setupNonGravForces      %% path, dependency report, and the NRLMSISE-00 fetch

Setup is the only part of the toolbox that touches the network. The NRLMSISE-00 C source is not redistributed here — its package carries no such grant — so setup clones it from its maintainer at a pinned commit the first time it runs, and prints a line saying so. 'FetchMsis', "never" leaves the network alone; NGF_NRLMSISE00 points at a copy you already have. Everything except the msis00 density backend works without it.

NonGravForces.buildMex          %% compile the two MEX gateways, once per machine
matlab -batch ciGate            %% the gate: Code Analyzer clean, then the whole suite

Then run a demo. Each is a working sequence of public calls, and each is EXECUTED BY THE GATE (tests/tNgfDemos.m), so an API that moves breaks the demo in CI rather than in front of a reader:

demoForceBudget         %% per-effect budget, two presets side by side
demoDensityInversion    %% recover a planted density scale
demoGraceFOCalibration  %% recover a planted bias and scale
demoCAI                 %% cold-atom accelerometer, and why it needs the attitude rate
