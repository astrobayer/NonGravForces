Tutorials

Step-by-step guides for a first-time user: one MATLAB script per task in tutorials/, written to be run cell by cell. Every step says what it does and why, which inputs it takes with their units and frames, and prints or plots what it produced. The pages below are the PUBLISHED scripts (tools/publishTutorials.m) with the output of a real run; the same tutorials, with code, recorded output and figures, form the first chapter of the user guide PDF. tests/tNgfTutorials.m runs every tutorial that needs no data pool in every gate.

setupNonGravForces             %% puts tutorials/ on the path
edit ngfTutorial01FirstSteps   %% then run it cell by cell (Ctrl+Enter)
  1. First steps: the toolbox, its data and one modelled acceleration (ngfTutorial01FirstSteps.m; requirements: none)
    • how to check that NonGravForces and its five sibling toolboxes are installed;
    • where the committed data live and what the reference day is;

    • how to build a NonGravForces.Model and call accel on an arc;
    • the units and frames of every input and output (SI, the body frame, GPS epochs).
